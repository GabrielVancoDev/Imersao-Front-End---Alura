# 🎧 Imersão Alura: Explorando os Dados do Spotify

Bem-vindo(a) ao repositório da **Imersão da Alura com Spotify**!  
Neste projeto, criamos uma experiência interativa baseada em dados do Spotify, utilizando tecnologias da web como JavaScript, HTML e CSS para visualizar e explorar informações musicais de forma dinâmica.

## 🚀 O que é essa imersão?

A **Imersão Alura** é uma experiência gratuita e intensiva promovida pela [Alura](https://www.alura.com.br/), que oferece uma jornada prática de aprendizado. Nesta edição, mergulhamos no universo do **Spotify**, desenvolvendo uma aplicação web que mostra dados musicais de maneira visual e acessível.

## 🛠️ Tecnologias e Ferramentas

- HTML5  
- CSS3  
- JavaScript (ES6+)  
- [Spotify Web API](https://developer.spotify.com/documentation/web-api/) 🎶

## 📂 Estrutura do Projeto

- `index.html` — Página principal do projeto  
- `style.css` — Estilização da interface  
- `script.js` — Lógica de interatividade e consumo de dados da API  
- `assets/` — Imagens e ícones utilizados na interface

## 👩‍💻 O que foi desenvolvido?

Durante a imersão, criamos:

- Interfaces web modernas e responsivas  
- Visualizações com dados reais do Spotify  
- Interações com API para buscar artistas, músicas e álbuns  
- Análises simples direto no navegador
